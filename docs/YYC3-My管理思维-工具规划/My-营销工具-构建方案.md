## 一、工具核心定位与价值

该工具并非传统节日查询器，而是深度嵌入 YYC³ 系统的 “节日数据中枢 + 营销动作触发器” ，核心解决三大问题：

1. 6 类节日的 “自动聚合 + 动态更新”，避免人工整理遗漏；
2. 节日与年度三阶段目标、月度节点的 “智能关联”，输出可视化运营节奏表；
3. 基于节日的 “营销动作预设 + 时效提醒”，衔接 YYC³ 营销、财务、客户运维等模块，实现自动化落地。

### 2. 节日 - 目标联动模块（可视化节奏规划）

#### （1）核心功能：三阶段自动适配与占比分配

工具基于节日 “流量等级” 与 “时间分布”，自动完成两项关键计算：

1. 阶段归属判定：按 “旺季（春节 / 国庆 / 暑期）、平季（520 / 端午）、淡季（双 11 / 冬至）” 规则，将节日归入对应阶段，生成《年度节日 - 阶段分布表》；
2. 目标占比拆分：参考历史营收贡献，为单个节日分配阶段目标占比（如春节占旺季目标的 40%→对应总目标 X×20%），并同步至 YYC³ 盈亏测算模块。

#### （2）可视化展示形式

复用开源日历组件（如 Web 端用 Vue 整合CalendarView、鸿蒙端用ossimplecalendarview），实现 “三视图联动”：

- 年视图：用不同颜色块标记 6 类节日，鼠标悬浮显示 “阶段归属 + 目标占比”；
- 月视图：叠加月度节点（月初开门红 / 中旬突破期等），用虚线框标注节日影响时段；
- 详情视图：点击节日显示 “核心动作清单”（如春节→推送团圆套餐 + 设备检修），并关联 YYC³ 对应模块入口。

### 2. 核心算法与逻辑实现

#### （1）农历节日公历转换算法（基于lunardate库）

```python
from lunardate import LunarDate
from datetime import datetime

def lunar_to_solar(festival_name, target_year=None):
    # 1. 定义农历节日与农历日期的映射关系
    lunar_festival_map = {
        "春节": (1, 1),    # 正月初一
        "端午节": (5, 5),  # 五月初五
        "中秋节": (8, 15)  # 八月十五
    }
    if festival_name not in lunar_festival_map:
        return "未收录该农历节日"

    # 2. 处理目标年份（默认当前年）
    if not target_year:
        target_year = datetime.now().year
    lunar_month, lunar_day = lunar_festival_map[festival_name]

    # 3. 转换农历到公历，处理跨年情况
    try:
        solar_date = LunarDate(target_year, lunar_month, lunar_day).toSolarDate()
        # 若当前日期已过当年节日，则自动计算下一年
        if solar_date < datetime.now().date():
            solar_date = LunarDate(target_year + 1, lunar_month, lunar_day).toSolarDate()
        return solar_date.strftime("%Y-%m-%d")
    except Exception as e:
        return f"日期转换失败：{str(e)}"
```

#### （2）节日 - 阶段归属判定逻辑

def get_festival_stage(festival_date_str):
    festival_date = datetime.strptime(festival_date_str, "%Y-%m-%d").date()
    month = festival_date.month
    # 旺季：1-2月（春节）、7-8月（暑期）、10月（国庆）
    if month in [1,2,7,8,10]:
        return "旺季攻坚"
    # 平季：3-6月（清明/520/端午）、9月（中秋/开学季）
    elif month in [3,4,5,6,9]:
        return "平季深耕"
    # 淡季：11-12月（双11/双12）
    else:
        return "淡季蓄能"

1. 工具自动抓取国务院下一年度放假安排，更新法定节假日；
2. 运营人员补充新增网络营销日（如新兴热点节日）或地方临时节日（如区域文旅节）；

## 六、用户角色专属功能（适配 KTV 全岗位需求）

### 1. 店长角色：节日节奏总控

#### （1）专属看板

### 2. 营销岗角色：节日活动精准落地

#### （1）专属功能

- 客户分层触达：工具自动关联客户运维模块的 RFM 标签，生成 “节日触达清单”（如高净值客户推送 “专属包厢 + 定制果盘”，新客户推送 “首单立减 50 元”）；

1. 工具自动抓取 “520 历史数据”（情侣客群占比 60%，客单价 280 元）；

3. 选择方案后，自动同步至客户运维模块（推送优惠券）、表单体系模块（生成活动反馈问卷）。

### 3. 财务岗角色：节日成本精准管控

#### （1）专属功能

#### （2）关键报表

- 《节日成本明细报表》：按 “酒水 / 物料 / 人力” 分项统计，标注 “超预算项”（如春节物料超支 2000 元，因主题布置成本上升）；

## 七、数据安全与合规保障（聚焦敏感数据保护）

### 1. 数据加密与脱敏

- 客户数据：节日推送的客户手机号、消费记录等敏感信息，传输采用 SSL 加密，存储时手机号脱敏（如 138****5678），仅授权营销岗查看完整信息；
- 财务数据：节日营收、成本数据采用国密 SM4 算法加密，调用需双因子认证（账号密码 + 手机验证码），操作日志留存 10 年备查。

### 2. 权限精细管控

基于 “最小必要原则” 设置权限，示例：

|数据类型|店长权限|营销岗权限|服务员权限|

### 3. 合规审计

- 节日活动合规校验：工具内置 “广告法合规库”，检测活动文案（如 “最优惠”“第一” 等违禁词），自动标红并提供替换建议（如 “最优惠”→“节日专属优惠”）；
- 定期审计报告：每月生成《节日数据合规报告》，包含 “敏感数据访问记录、异常操作记录”，支持对接企业审计系统。

本工具是 YYC³ 经管运维全链路的**执行引擎**，接收上游目标，驱动下游动作：

   ↓

   ↓
【下游】反馈至目标量化文档
   └─ 节日实际营收 vs X×占比 → 偏差率＞20% 时触发目标回调

**关键数据接口**：

- 输入：X 值（来自目标量化）、城市成本指数（来自成本计算工具）
- 输出：节日实际营收达成率、资源消耗率、竞品应对效果（回流至目标量化与成本计算）
