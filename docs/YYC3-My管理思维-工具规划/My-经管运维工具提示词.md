## 一、经营成本与盈亏计算核心提示词

> 对应文档：《实体行业经营成本、盈亏计算工具》
> 适用场景：KTV/实体门店的投资测算、盈亏分析、经营决策

### 1.1 城市数据适配提示词

```
你是一个实体行业经营测算专家，请基于以下维度对 [城市名称] 进行经营环境评估：

1. 城市等级划分：一线 / 新一线 / 二线 / 三线 / 四线 / 五线
2. 核心经济指标：
   - 人均可支配收入（元/年）
   - 娱乐消费占比（%）
   - 商业租金指数（元/㎡/月）
   - 行业竞争密度（门店数/万人）
3. 区域修正系数：基于该城市所在区域（华东/华南/华北/华中/西南/西北/东北）的消费习惯修正
4. 输出格式：按上述维度输出结构化的城市评估报告，并给出适配该城市的经营建议
```

### 1.2 动态成本核算提示词

```
你是一个实体行业成本核算师，请基于以下模型进行动态成本核算：

【核心算法】城市成本指数 = 基础成本 × 消费等级系数 × 区域修正值

核算维度：
1. 场地成本：总面积 × 商业租金指数 × 场地利用率（%）
   - 包厢配置：小包（15-20㎡）、中包（25-35㎡）、大包（40-60㎡）、VIP（80-120㎡）
   - 装修档次：经济型（800-1200元/㎡）/ 标准型（1200-2000元/㎡）/ 豪华型（2000-3500元/㎡）
2. 设备成本：
   - 音响系统：经济/标准/专业 三档
   - 点歌系统
   - 灯光系统
   - 选配：VR/AR 系统、无人值守系统
   - 分析维度：设备总投资、折旧年限、回收期
3. 运营成本：
   - 人力成本：员工数量 × 平均工资（含社保）
   - 能耗成本：营业时间 × 单位能耗 × 电价
   - 物料成本：客流量 × 单客物料消耗
4. 输出：分项成本明细 + 总成本报告 + 优化建议
```

### 1.3 盈亏分析提示词

```
你是一个实体店经营分析师，请基于以下数据生成盈亏分析报告：

输入参数：
- 月总成本：[金额]
- 日均客流量：[人数]
- 人均消费：[金额]
- 包厢数量及类型分布
- 营业时段：非高峰/高峰/深夜

分析模型：
1. 收入预测：
   - 包厢收入 = 包厢数 × 时段利用率 × 动态定价 × 翻台率
   - 酒水收入 = 客流量 × 酒水人均消费
   - 其他收入（小费、活动、会员费等）
2. 利润计算：月总收入 - 月总成本 = 月利润
3. 关键指标：毛利率、净利润率、投资回收期、ROI
4. 最优包厢配置 = max(包厢面积 × 时段利用率 × 动态定价)
5. 敏感性分析：客流量 ±10%、人均消费 ±10%、成本 ±10% 对利润的影响

输出格式：
- 损益表（月度）
- 关键经营指标仪表盘
- AI 优化建议（分短期/中期/长期）
- 风险预警（低于盈亏平衡点的距离）
```

## 二、节日管理与营销适配核心提示词

> 对应文档：My-营销工具-构建方案.md（③ 执行引擎）
> 适用场景：全年度节日营销策划、资源预配、竞品应对

### 2.1 节日数据聚合提示词

```
你是一个节日营销数据专家，请构建一个完整的节日日历，覆盖以下 6 类节日：

1. 法定节假日：元旦、春节、清明、劳动节、端午、中秋、国庆
2. 民俗节假日：元宵节、七夕、重阳节、腊八节、小年等
3. 网络营销日：情人节（2.14）、白色情人节（3.14）、520（5.20）、双11、双12、圣诞
4. 地方特殊假日：根据 [城市/省份] 的地方性假日（如泼水节、那达慕等）
5. 品牌庆典日：品牌周年庆、会员日、品牌日
6. 门店活动日：店庆月、门店主题活动日

每个节日需包含以下核心字段：
- 节日 ID、名称、日期范围（起止日期）、类型（1-6类）、归属阶段（旺季/平季/淡季）
- 区域适配性（全国/区域/城市/门店级）
- 历史营销数据（往年同期收入、客流量、转化率）
- 目标占比：该节日在所属阶段的营收占比权重

输出：结构化节日日历表，按时间轴排列，标注每个节日的类型、阶段、权重
```

### 2.2 三阶段目标联动提示词

```
你是一个年度目标拆解专家，请将年度总目标 [X] 按三阶段拆解到节日粒度：

【目标三阶段框架】
- 旺季攻坚（爆点）50% | 约 102 天 | 锚定：春节 / 国庆 / 暑期
- 平季深耕（稳点）30% | 约 153 天 | 锚定：清明 / 端午 / 520 / 七夕
- 淡季蓄能（躺平优化）20% | 约 110 天 | 锚定：双11 / 双12 / 元旦

拆解步骤：
1. 第一阶段：X → 三阶段（旺季50%/平季30%/淡季20%）
2. 第二阶段：阶段目标 → 月度目标（按季节指数分配）
3. 第三阶段：月度目标 → 周目标 → 日目标

联动规则：
- 节点日期 7 天前：自动触发营销准备动作
- 节点日期当天：执行营销活动
- 节点日期后 3 天：执行复盘与数据收集
- 目标偏差预警：当实际 < 目标 × 80% 时触发预警

输出：年度目标拆解时间轴 + 各节点目标值 + 预警阈值
```

### 2.3 营销动作自动化提示词

```
你是一个营销自动化运营专家，请为以下节日/节点生成完整的营销动作配置：

输入：节日名称 [ ] | 日期范围 [ ] | 类型 [ ] | 阶段 [旺季/平季/淡季]

动作触发链（按时间轴）：
1. 节前 7 天 -> 营销准备阶段：
   - 活动方案定稿
   - 物料设计与制作（海报、短视频、推文）
   - 包厢资源预配（调整包厢类型占比）
   - 酒水库存预配（根据历史数据 + 节日特色）
   - 人力排班预配（增加临时工/调整班次）
2. 节日当天 -> 执行阶段：
   - 多渠道营销投放（公众号/抖音/美团/朋友圈）
   - 门店氛围布置
   - 实时客流监控与动态定价调整
   - 竞品价格实时监控与应对
3. 节后 3 天 -> 复盘阶段：
   - 经营数据收集（收入/客流/客单价/转化率）
   - 活动效果评估（ROI / 同比 / 环比）
   - 客户反馈收集
   - 复盘报告生成
   - 经验沉淀到数据库

竞品应对策略：
- 竞品降价应对：差异化赠品 / 增值服务 / 会员积分翻倍
- 竞品活动应对：错位竞争（不同主题/不同时段）
- 竞品新品应对：针对性体验升级

输出：
1. 营销节奏甘特图（按天）
2. 资源配置清单（包厢/酒水/人力/物料）
3. 竞品应对预案
4. 关键 KPI 目标值
```

## 三、年度营销策划核心提示词

> 对应文档：《YYC³ 营销策划案》
> 适用场景：年度营销目标设定、月度节点细化、活动策划

### 3.1 年度目标设定提示词

```
你是一个实体行业年度营销策划专家，请基于以下公式设定年度营收总目标：

【年度目标公式】
X（年度营收总目标）= 基础营收基数 × 城市等级系数 × 门店规模系数 × 行业增速系数 × 调整系数

各变量定义：
1. 基础营收基数：上年度实际营收额
   - 若为新店：参考同城同规模门店均值
2. 城市等级系数：
   - 一线城市：1.2-1.5
   - 新一线：1.0-1.2
   - 二线城市：0.8-1.0
   - 三线城市：0.6-0.8
   - 四线及以下：0.4-0.6
3. 门店规模系数：
   - 小型（<1500㎡）：0.7-0.9
   - 中型（1500-3000㎡）：0.9-1.1
   - 大型（>3000㎡）：1.1-1.3
4. 行业增速系数：参考本年度娱乐行业预测增速（%）
5. 调整系数：0.8-1.2，根据门店实际经营状况调整

输出：
- X 值计算过程（每一步的取值依据）
- 目标合理性评估（与行业标杆对比）
- 增长动力分解（量价拆分：客流增长 vs 客单价提升）
```

### 3.2 月度节点细化提示词

```
你是一个月度营销策划师，请基于以下框架为 [月份] 设计细化的营销执行方案：

【月度目标分配框架】以月度目标为 X
- 月初开门红（5%）：X × 5% — 1-5日 | 动作：会员回馈 / 积分兑换 / 月度活动预告
- 上旬消费高峰（25%）：X × 25% — 6-10日 | 动作：抢占周末黄金档 / 主题派对夜
- 中旬突破期（20%）：X × 20% — 11-20日 | 动作：跨界合作 / 异业联盟 / 团购冲刺
- 下旬突破期（30%）：X × 30% — 21-25日 | 动作：节日活动冲刺 / 会员专属活动
- 月末收官期（20%）：X × 20% — 26-月末 | 动作：未达标提醒 / 会员储值冲刺 / 下月预热

输入信息：
- 月份：[ ]
- 该月包含的节假日：[ ]
- 所属阶段：旺季 / 平季 / 淡季
- 月度目标 X：[金额]
- 门店基本信息：[包厢数 / 员工数 / 历史数据]

输出格式：
- 月度营销日历（按周/日细化）
- 各阶段 KPI 分解表
- 预算分配方案
- 风险预案（含天气/疫情/政策等不可抗力）
```

### 3.3 营销活动策划提示词

```
你是一个实体店营销活动策划师，请为 [节日/活动名称] 设计完整的营销活动方案：

活动基本信息：
- 活动名称：[ ]
- 活动时间：[ ]
- 活动主题：[ ]
- 目标人群：[ ]

策划维度：
1. 定价策略：
   - 包厢定价：时段差异化定价 / 套餐定价 / 会员价
   - 酒水定价：套餐搭配 / 买赠策略 / 特价引流
   - 会员专属价
2. 促销策略：
   - 引流品（低价/免费吸引到店）
   - 利润品（高毛利产品组合）
   - 连带推荐机制
3. 渠道策略：
   - 线上：抖音团购 / 美团点评 / 公众号 / 私域社群
   - 线下：门店海报 / 地推 / 异业合作
4. 会员策略：
   - 新客转化：首次体验价 / 赠送券包
   - 老客复购：积分翻倍 / 储值赠金 / 专享折扣
   - 沉睡唤醒：专属优惠 / 生日特权

活动 ROI 测算：
- 投入成本：营销费用 + 让利成本 + 物料成本 + 人力成本
- 预期产出：新增客流 × 客单价 + 会员新增 × 年度 LTV + 品牌曝光价值
- ROI 目标：≥ 3.0

输出：
- 完整的活动策划书（含执行时间表）
- 预算明细表
- 效果预测（含悲观/中性/乐观三档）
- 风险预案
```

## 四、综合应用提示词（跨工具联动，④ 驱动核心自身能力）

### 4.1 经营诊断与营销联动提示词

```
你是一个实体行业经营诊断师，请结合成本数据与营销数据，对门店进行全面诊断：

输入：
- 近 [3/6/12] 个月的经营数据（收入/成本/利润/客流量）
- 期间内执行的营销活动清单
- 节假日日历

诊断维度：
1. 成本健康度：各项成本占比是否合理 → 触发成本优化建议
2. 营销效率：各活动的 ROI 排序 → 识别高效/低效活动
3. 节日利用率：哪些节日被充分利用 → 哪些节日被浪费
4. 会员健康度：新增/留存/活跃/沉睡会员比例

输出：
1. 经营健康度仪表盘（红/黄/绿三色预警）
2. 营销活动效能排名
3. 下阶段优化建议（成本侧 + 营销侧双线）
4. 节日营销日历优化建议
```

### 4.2 全流程经营规划提示词

```

阶段二：目标设定

阶段三：成本预算
- 场地/设备/人力/运营成本预算
- 成本优化空间分析

阶段四：营销策划
- 年度节日日历标注
- 各节点营销动作规划

阶段五：执行监控
- 核心 KPI 看板

- 月度复盘与调整机制

输出：《[门店名称] 年度经营规划书》完整文档
```

### 5.5 全链路执行 Prompt（一键启动端到端经营规划）

```
你是一个 YYC³ 全链路经管运维专家，请按以下 5 个阶段完成端到端经营规划：

【阶段1：目标设定】（对应文档①）
- 输入：门店城市、包厢数、上年度营收、行业增速
- 执行：用 X 公式计算年度总目标
- 输出：X 值 + 三阶段拆分（旺季50%/平季30%/淡季20%）

【阶段2：成本校验】（对应文档②）
- 输入：城市等级、场地面积、包厢配置、设备档次
- 执行：计算月度总成本，校验 X/12 - 月总成本 = 月预期利润
- 判断：利润率 ≥ 15% → 通过；＜ 15% → 回调 X
- 输出：盈亏平衡点 + 成本结构

【阶段3：节奏规划】（对应文档③）
- 输入：年度节日日历、三阶段 X 占比
- 执行：6 类节日归入阶段，分配 X×占比 到每个节日
- 输出：节日-阶段分布表 + 月度节点匹配表

【阶段4：动作执行】（对应文档③）
- 输入：节日列表、资源预配清单
- 执行：按"节前7天→节中→节后3天"触发营销动作
- 输出：营销动作执行清单 + 资源配置单

【阶段5：复盘回调】（闭环）
- 输入：节日实际营收、成本消耗、竞品动态
- 执行：对比实际 vs 目标，计算偏差率
- 判断：偏差＞20% → 回到阶段1调整 X；偏差≤20% → 沉淀经验进入下一周期
- 输出：《经营复盘报告》+ X 值调整建议
```
